# Тестирование формы записи на мастер-класс по свечеварению

[Открыть приложение на GitHub Pages](https://qahelping.github.io/aqa-candels/)

## Высокоуровневые требования

1. Форма предназначена для записи на офлайн-мастер-класс по свечеварению.
2. Запись доступна любому посетителю без регистрации и входа в аккаунт.
3. Имя и фамилия вводятся в одно обязательное поле.
4. Для связи участник указывает email. Поле обязательное. 
5. Участник обязательно выбирает дату из выпадающего списка. 
6. [Временнные данные] Занятия проходят в ноябре по вторникам и четвергам в 19:00 по Минску. На старте на 17, 19 и 24 ноября доступно по одному месту, на 26 ноября — пять.
7. В списке отображаются только даты со свободными местами. После успешной записи число свободных мест на выбранную дату уменьшается на одно. Когда мест больше нет, дата исчезает из списка.
8. Участник прикрепляет чек об оплате перед отправкой заявки. Статус оплаты подтверждает администратор после проверки чека.
9. После успешной отправки форма показывает участнику подтверждение записи на выбранную дату.
10. [Следующая итерация] В полной версии заявки попадают в Google Таблицу на отдельную вкладку для каждой даты. До проверки администратором статус оплаты — «На проверке», после подтверждения — «Оплачено».

В этой версии опубликована демонстрационная форма. Отправка заявки и изменение числа мест имитируются в открытой вкладке. После обновления страницы исходное число мест восстанавливается. Хранение чеков и заявок, проверка оплаты администратором и интеграция с Google Таблицей относятся к следующим этапам.
